# Business Hub Dashboard

Build a modern, sleek SaaS web dashboard for a business management platform.

Global Settings & UI Requirements:

- Theme Switcher: Toggle between Light Mode (bright, clean slate background) and Dark Mode (sleek, low-contrast dark theme) in the header.

- Language Selector: Dropdown in the header allowing users to switch languages (include English, Spanish, French, German, and Portuguese).

Main Sections in Left Sidebar Menu:

1. Dashboard / Today's Briefing: Overview of upcoming meetings, missed calls, and top action items for the day.

2. Unified Calendar: Day/Week/Month view with an "Add Meeting" button and an "Add Custom Event" modal with custom tags, colors, and notes.

3. Communication Inbox: Split view showing tabs for Emails, WhatsApp Messages, and Phone SMS/Missed Calls.

4. Contacts / Client Timeline: List of clients where clicking a contact shows a unified history of emails, calls, and meetings.

Design style: Modern, professional, responsive UI. Use interactive mock data so I can click around, switch themes, and test the features.
